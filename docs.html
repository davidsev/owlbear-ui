Installation

npm install @davidsev/owlbear-ui

Then import in your code:

// Import everything:
import '@davidsev/owlbear-ui';

// Color picker is a separate import (vanilla-colorful is optional):
import '@davidsev/owlbear-ui/color-picker';

// Or import individual components to reduce bundle size:
import '@davidsev/owlbear-ui/components/Button';
import '@davidsev/owlbear-ui/components/Select';
import '@davidsev/owlbear-ui/core/ThemeManager';

ThemeManager

The ThemeManager singleton injects a global stylesheet with CSS custom properties and sets data-theme on <html>. It is lazily instantiated on the first getInstance() call and defaults to dark mode.

Usage

import { ThemeManager } from '@davidsev/owlbear-ui';

const tm = ThemeManager.getInstance();

// In an OBR extension — sync with OBR's theme:
tm.connectOBR();

// Manual control:
tm.setTheme('light');
tm.setTheme('dark');

// Read current state:
console.log(tm.darkMode); // boolean

// Listen for changes:
tm.addEventListener('change', () => {
    console.log('Theme is now', tm.darkMode ? 'dark' : 'light');
});

API

MemberTypeDescription
ThemeManager.getInstance()static methodReturns the singleton instance.
.darkModeboolean (readonly)true if current theme is dark.
.setTheme(mode)methodManually set the theme. Accepts 'dark' or 'light'.
.connectOBR()async methodStart syncing with OBR's theme. Dynamically imports @owlbear-rodeo/sdk.

BaseElement

Base class for all owlbear-ui components and for your own custom components. Extends LitElement.

import { html } from 'lit';
import { customElement } from 'lit/decorators.js';
import { BaseElement, baseCSS } from '@davidsev/owlbear-ui';

@customElement('my-widget')
class MyWidget extends BaseElement {
    static override styles = baseCSS(`
        :host { padding: 1rem; }
        p { color: var(--theme-color); }
    `);

    override render() {
        return html`<p>My themed widget</p>`;
    }
}

API

MemberDescription
eventCleanupSignalProtected AbortSignal that aborts when the element is disconnected. Pass as { signal } to addEventListener for automatic cleanup.

FormElement

Base class for owlbear-ui's form-control components (<obui-input>, <obui-select>, <obui-multi-select>, <obui-slider>). Extends BaseElement and attaches ElementInternals, so HTML constraint-validation state (e.g. from required) is exposed directly on the host element — callers never need to reach into the shadow root to find the underlying native control.

import { FormElement } from '@davidsev/owlbear-ui';

const input = document.querySelector('obui-input[required]');

input.validity.valueMissing; // true if empty
input.validationMessage;     // browser's default message, or your custom one
input.checkValidity();       // true/false, fires 'invalid' if false
input.reportValidity();      // like checkValidity(), but also shows the native validation bubble
input.willValidate;          // false if barred from constraint validation
input.form;                  // the associated <form>, or null

The constraint-validation API is synchronous — reading validity or calling checkValidity() flushes any pending render first, so el.required = true; el.checkValidity() sees the new state without awaiting updateComplete.

disabled mirrors a bare <input>: the element is barred from constraint validation, so willValidate is false, checkValidity() returns true and validationMessage is empty. An enclosing <fieldset disabled> does the same and also disables the control itself.

These are form-associated custom elements, so they behave like native controls inside a <form>:

  • The value is submitted under name — unnamed and disabled controls submit nothing, as native ones do. <obui-multi-select> submits one entry per selection, like <select multiple>.
  • An invalid control blocks submission and shows the browser's validation bubble.
  • For the selects, a value that isn't one of options counts as nothing selected — for display, validity and submission alike.
  • form.reset() restores the value the control was authored with — its value attribute, as with a native control's defaultValue. Assigning .value from JS later doesn't move that default.
<form>
    <obui-input name="who" value="Ada" required></obui-input>
    <obui-multi-select name="colours"></obui-multi-select>
    <button type="submit">Save</button>
</form>

<script type="module">
    form.addEventListener('submit', (e) => {
        e.preventDefault();
        [...new FormData(form)]; // [['who', 'Ada'], ['colours', 'red'], ['colours', 'blue']]
    });
</script>

Browser state restoration (autofill, back/forward navigation) is not implemented — there is no formStateRestoreCallback.

API

MemberDescription
validityRead-only ValidityState of the host element.
validationMessageRead-only. The validation message, if any. Empty when the element is valid or barred from validation (e.g. disabled).
willValidateRead-only boolean. Whether the element is a candidate for constraint validation.
nameName the value is submitted under. Backed by the name attribute, as on a native control.
disabledboolean, reflected. Also set by an ancestor <fieldset disabled>, which disables the control without touching this property.
formRead-only. The associated <form>, or null.
checkValidity()Returns true/false; fires a cancellable invalid event if invalid.
reportValidity()Like checkValidity(), but also shows the browser's native validation bubble on the element if invalid.

<obui-select>

A single-value dropdown. Options are set via the options property (a Record<string, string> mapping keys to display labels). Opens on focus, supports keyboard navigation.

<obui-select id="my-select" placeholder="Choose..."></obui-select>

<script>
const select = document.getElementById('my-select');
select.options = {
    circle: 'Circle',
    square: 'Square',
    triangle: 'Triangle',
};
select.value = 'square'; // pre-select

select.addEventListener('change', (e) => {
    console.log('selected:', e.target.value);
});
</script>

valuevaluestring""Currently selected key.
placeholderplaceholderstring""Text shown when no value is selected.
namenamestring""Name the value is submitted under in a native <form>. See FormElement.
disableddisabledbooleanfalseWhen true, prevents interaction and applies disabled styling.
requiredrequiredbooleanfalseInvalid while no option is selected. See FormElement for validity/checkValidity().
ariaLabelaria-labelstring | nullnullAccessible label for the combobox. Applied to the listbox element.

Events

EventDetailDescription
changenoneFired when a new option is selected. Read .value for the selected key.

Keyboard

Accessibility

The host element has role="combobox" with aria-expanded, aria-haspopup="listbox", and aria-activedescendant. The dropdown has role="listbox" and each option has role="option" with aria-selected.

<obui-tab-bar> + <obui-tab-button>

A tab bar that manages tab buttons. Each <obui-tab-button> can target an element to show/hide via CSS selector or element reference. Follows the WAI-ARIA Tabs pattern with role="tablist", role="tab", and keyboard navigation.

Settings Appearance About
Settings panel content.
Appearance panel content.
About panel content.
<obui-tab-bar id="tabs">
    <obui-tab-button active target="#panel-a">Settings</obui-tab-button>
    <obui-tab-button target="#panel-b">Appearance</obui-tab-button>
    <obui-tab-button target="#panel-c">About</obui-tab-button>
</obui-tab-bar>
<div id="panel-a">Settings content.</div>
<div id="panel-b" style="display: none;">Appearance content.</div>
<div id="panel-c" style="display: none;">About content.</div>

<script>
document.getElementById('tabs').addEventListener('tab-change', (e) => {
    console.log('switched to:', e.detail.tab.textContent);
});

// Programmatic selection:
document.getElementById('tabs').selectTab('about-tab');    // by element id
document.getElementById('tabs').selectTab(tabButtonRef);  // by reference
document.getElementById('tabs').selectTab(null);          // deselect all
</script>

<obui-slider>

A range slider with a theme-coloured filled track and a circular thumb, styled to match Owlbear Rodeo's UI. Built on a native <input type="range">, so keyboard (arrows, Home/End, Page Up/Down), touch and screen-reader support come for free. Optional tick marks via the ticks property — n ticks divide the track into n + 1 equal segments, so ticks="3" marks the quarter points.

Default (0–100)
Stepped, 3 ticks (quarters)
Continuous (0–1)
Disabled
<obui-slider min="0" max="100" value="50"></obui-slider>
<obui-slider min="0" max="20" step="5" value="10" ticks="3"></obui-slider>

<script>
const slider = document.querySelector('obui-slider');

// Fires continuously while dragging or on each keyboard step:
slider.addEventListener('input', () => console.log(slider.value));

// Fires once when the value is committed (pointer release / keyboard):
slider.addEventListener('change', () => console.log('committed:', slider.value));
</script>

<obui-button-group> + <obui-button-group-item>

A segmented control — a group of mutually-exclusive buttons. Exactly one item is selected; the selected value lives on the group's value property. Each <obui-button-group-item> carries a value and can contain text, an icon, or both. Follows the WAI-ARIA radio group pattern with role="radiogroup", role="radio", roving tabindex, and arrow-key navigation.

☽ Dark ☀ Light Outline Squircle Circle 
<obui-button-group value="circle" aria-label="Border style">
    <obui-button-group-item value="outline">Outline</obui-button-group-item>
    <obui-button-group-item value="squircle">Squircle</obui-button-group-item>
    <obui-button-group-item value="circle">Circle</obui-button-group-item>
</obui-button-group>

<script>
const group = document.querySelector('obui-button-group');
group.addEventListener('change', () => console.log(group.value));

// Programmatic selection (does NOT fire change):
group.value = 'squircle';
</script>

<obui-button-group> API

PropertyAttributeTypeDefaultDescription
valuevaluestring""The selected item's value. Set programmatically to change the selection (does not fire change).
disableddisabledbooleanfalseDisables the whole group.
ariaLabelaria-labelstring | nullnullAccessible label for the radio group.
EventDetailDescription
changenoneFired when the selection changes via user interaction (click or keyboard). Read .value. Not fired on programmatic value changes.

<obui-button-group-item> API

PropertyAttributeTypeDefaultDescription
valuevaluestring""The item's value, surfaced on the group when selected.
selectedselectedbooleanfalseWhether this item is selected. Managed by the parent group — reflected for styling via :host([selected]).
disableddisabledbooleanfalseDisables this item only; it is skipped by keyboard navigation and ignores clicks.
ariaLabelaria-labelstring | nullnullAccessible name for the radio. Required for icon-only segments (text segments take their name from the slotted text).

Note: the group manages each item's selected state and roving tabindex, re-syncing when items are added or removed (or when the group's own value/disabled changes). Change an item's value or disabled by re-rendering the items rather than mutating a live item in place — an in-place mutation isn't observed by the group, so the selection and tab order can go stale.

<obui-color-picker>

A color swatch button that opens a hex+alpha color picker in a modal dialog. Requires vanilla-colorful as an optional peer dependency. The swatch button has aria-haspopup="dialog". Focus moves into the dialog on open and returns to the swatch on close.

Separate import:

import '@davidsev/owlbear-ui/color-picker';
Default
Red, 50% opacity
Named color
<obui-color-picker color="#ff0000" opacity="0.5"></obui-color-picker>

<script>
const picker = document.querySelector('obui-color-picker');

// Fires continuously while dragging:
picker.addEventListener('input', () => {
    console.log(picker.color);   // "#ff0000" (6-char hex)
    console.log(picker.opacity); // 0.5 (0-1)
    console.log(picker.hexa);    // "#ff000080" (8-char hex)
});

// Fires once when the picker dialog closes:
picker.addEventListener('change', () => {
    console.log('committed:', picker.color, picker.opacity);
});
</script>
